## Harish Reddy — Portfolio

Personal portfolio built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Customize content

- **Edit profile data**: `src/lib/profile.ts`
- **Edit page layout/sections**: `src/app/page.tsx`

## Deploy

Deploy easily on Vercel:
- Connect the repo and choose the default Next.js settings.
- After you have a real domain, consider adding `metadataBase` in `src/app/layout.tsx` for better Open Graph URLs.
